Computer Awareness Cheat Code: 15 Must-Know Facts

Published on December 24, 2025 | For IBPS, SBI, RBI & SSC Exams

Computer Awareness questions in banking and SSC exams keep returning to the same basics. Master these 15 Computer facts to cover the topics asked most often in IBPS, SBI, RBI and SSC papers.

Malware: Know the Difference

  • Virus — attaches to a file and spreads only when that file is run.
  • Worm — copies itself across a network without needing a host file or user action.
  • Trojan — looks like useful software but opens a back door.
  • Ransomware — encrypts your files and demands payment (e.g., WannaCry, 2017).
  • Spyware / keylogger — secretly records activity or keystrokes, such as banking passwords.

Number-System Conversion in 30 Seconds

To convert decimal 25 to binary, keep dividing by 2 and read the remainders from bottom to top: 25 → 12 r1 → 6 r0 → 3 r0 → 1 r1 → 0 r1, so 25 = 11001. In hexadecimal, A–F stand for 10–15, so FF = 255; one hex digit equals four binary digits, which is why 1111 1111 = FF.

⚠️ Common traps: "1 KB = 1,000 bytes" is the answer exam keys reject — use 1,024. ROM is non-volatile, not "read-only for the user". A worm does not need a host program; a virus does.

❓ Frequently Asked Questions

How many Computer Awareness questions come in bank exams?

There is no fixed number. In most bank Mains papers, computer questions are part of a combined section such as "Reasoning & Computer Aptitude", and clerk-level papers may include them with general awareness. The latest notification lists the exact section break-up.

What is the difference between a compiler and an interpreter?

A compiler translates the whole program into machine code before it runs, while an interpreter translates and executes it one line at a time. Compiled programs usually run faster; interpreted ones are easier to debug.

Which is faster, cache or RAM?

Cache is faster. It is a small memory between the CPU and RAM that stores frequently used data. Only CPU registers are faster than cache.

Remainder Theorem for Polynomials: Put x = a, Find the Remainder, Test Factors and Find Unknown Coefficients

Remainder = p(a) • Dividing by x + a • Dividing by ax − b • Factor theorem: p(a) = 0 • Finding an unknown coefficient • Sum of coefficients = p(1)

SSC 📅 Last updated: 2026-11-03

When a polynomial p(x) is divided by (x − a), the remainder is simply p(a). There is no need for long division.

Remainder when p(x) ÷ (x − a) = p(a)

The reason is short. Every division can be written as p(x) = (x − a) × q(x) + r, where r is a constant. Putting x = a makes (x − a) zero, so p(a) = r. That one line is the whole remainder theorem for polynomials.

Worked example 1: divide by (x − 2)

p(x) = x³ − 2x² + 4x − 5. Put x = 2: 8 − 8 + 8 − 5 = 3.

For a divisor (x + a), set it to zero: x = −a. Signs are where most mistakes happen, so write the substitution out in brackets.

Worked example 2: divide by (x + 1)

Same p(x). Put x = −1: (−1)³ − 2(−1)² + 4(−1) − 5 = −1 − 2 − 4 − 5 = −12.

Worked example 3: a fourth-degree polynomial

x⁴ + x³ − 2x² + x + 1 divided by (x + 2). Put x = −2: 16 − 8 − 8 − 2 + 1 = −1. Even powers of a negative number are positive; odd powers keep the minus sign.

For a divisor (ax − b), the value to substitute is the root of the divisor, x = b/a.

Worked example 4: divide by (2x − 1)

p(x) = 4x³ − 2x + 7. Put x = 1/2: 4 × 1/8 − 1 + 7 = 0.5 − 1 + 7 = 6.5.

Working in fractions such as 1/2, 1/8 and 1/4 keeps the arithmetic exact. Decimals work too, as long as you do not round.

If the remainder is zero, the divisor divides the polynomial exactly. So:

(x − a) is a factor of p(x) if and only if p(a) = 0

Worked example 5: is (x − 1) a factor of x³ − 6x² + 11x − 6?

p(1) = 1 − 6 + 11 − 6 = 0, so yes.

A quick test for (x − 1): it is a factor exactly when the coefficients add up to zero, because p(1) is the sum of the coefficients. For (x + 1), compare the sum of the even-power coefficients with the sum of the odd-power ones.

Worked example 6: the other factors

Dividing out (x − 1) leaves x² − 5x + 6 = (x − 2)(x − 3). Checking p(2) = 0 and p(3) = 0 confirms all three roots, 1, 2 and 3, whose product is 6, matching the constant term's size.

For integer roots, try only the divisors of the constant term. Here the candidates were ±1, ±2, ±3 and ±6, which is a short list to test.

If a question says the polynomial is divisible by (x − a), or leaves a given remainder, set p(a) equal to that value and solve for the unknown.

Worked example 7: 2x³ + kx² − 5x + 2 divisible by (x − 2)

p(2) = 16 + 4k − 10 + 2 = 8 + 4k = 0, so k = −2.

With two unknowns, the question will give two conditions. Each condition is one equation, and the pair is solved as in linear equations.

Putting x = 1 into any polynomial adds up its coefficients. This answers "sum of the coefficients" questions without expanding anything.

Worked example 8: (3x − 2)⁵

The sum of the coefficients is (3 − 2)⁵ = 1. Expanding the bracket would take far longer.

In the same way, putting x = 0 gives the constant term: for (3x − 2)⁵ it is (−2)⁵ = −32. Putting x = −1 gives the alternating sum of the coefficients, which is how the (x + 1) factor test works.

For identities used in these expansions, see algebraic identities.

  • Using x = a for a divisor (x + a). Substitute x = −a.
  • Losing signs with negative powers. (−2)³ = −8 but (−2)⁴ = +16.
  • Using x = b for a divisor (ax − b). Substitute x = b/a.
  • Forgetting the constant term. It is part of p(a).
  • Expecting a number when dividing by a quadratic. The remainder can then be linear.

Q1. What is the remainder when x³ + 3x² − 5x + 4 is divided by (x − 1)? easy

✅ Answer: (d) 3

💡 Explanation: Put x = 1: 1 + 3 − 5 + 4 = 3.

Q2. What is the remainder when 2x³ − x² + 3x − 1 is divided by (x + 1)? easy

✅ Answer: (b) −7

💡 Explanation: Put x = −1: −2 − 1 − 3 − 1 = −7. Dividing by x + 1 means putting x = −1, not x = 1.

Q3. For what value of k is x³ − kx + 6 divisible by (x − 3)? medium

✅ Answer: (a) 11

💡 Explanation: By the factor theorem, p(3) = 0: 27 − 3k + 6 = 0, so k = 11.

Q4. What is the remainder when 8x³ − 4x² + 2x − 1 is divided by (2x − 1)? medium

✅ Answer: (c) 0

💡 Explanation: Put x = 1/2: 1 − 1 + 1 − 1 = 0. So 2x − 1 is in fact a factor.

Q5. Which of these is a factor of x³ − 7x + 6? easy

✅ Answer: (a) x − 1

💡 Explanation: p(1) = 1 − 7 + 6 = 0, so x − 1 is a factor. p(−1), p(3) and p(−2) all equal 12, not 0.

Why does putting x = a give the remainder?

Any division can be written p(x) = (x − a) × q(x) + r, where the remainder r is a constant. Putting x = a makes the first term zero, leaving p(a) = r.

What value do I put for a divisor like 2x + 3?

Set the divisor to zero and solve: 2x + 3 = 0 gives x = −3/2. The remainder is p(−3/2).

What if the divisor is a quadratic?

Then the remainder can be a linear expression ax + b, not a single number. Use the two roots of the quadratic to get two equations for a and b.

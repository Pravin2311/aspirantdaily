Laws of Indices and Surds: Exponent Rules, Fractional Powers, Equations and Comparing Surds

Seven exponent rules • Negative and fractional powers • Equations with the same base • Comparing surds by equalising the root • Rationalising

SSC Banking Railway 📅 Last updated: 2026-11-02

In aⁿ, a is the base and n is the index (or exponent). Almost every surds and indices question in SSC and banking papers reduces to the same short list of rules. For any non-zero base a and b:

RuleFormExample
Productaᵐ × aⁿ = aᵐ⁺ⁿ2³ × 2⁴ = 2⁷
Quotientaᵐ ÷ aⁿ = aᵐ⁻ⁿ5⁶ ÷ 5² = 5⁴
Power of a power(aᵐ)ⁿ = aᵐⁿ(3²)³ = 3⁶
Power of a product(ab)ⁿ = aⁿbⁿ(2 × 5)³ = 2³ × 5³
Zero indexa⁰ = 17⁰ = 1
Negative indexa⁻ⁿ = 1/aⁿ2⁻³ = 1/8
Fractional indexa^(p/q) = (q-th root of a)ᵖ8^(2/3) = 2² = 4

The laws of indices only combine powers of the same base in the product and quotient rules. 2³ × 3⁴ cannot be merged into a single power; the bases must first be rewritten, for example 4 as 2² or 27 as 3³.

Worked example 1: the product rule

2³ × 2⁴ = 8 × 16 = 128, and 2⁷ = 128. Adding the indices gives the same result: true.

A negative index means a reciprocal, and a fractional index means a root. Read a^(p/q) as "take the q-th root, then raise to the power p". Taking the root first keeps the numbers small.

Worked example 2: 81^(3/4)

The fourth root of 81 is 3, and 3³ = 27. Working the other way, 81³ = 531,441 and its fourth root is still 27, but that route is much slower.

Worked example 3: a negative fractional index

(27/8)^(−2/3): flip the fraction to remove the minus sign, giving (8/27)^(2/3). The cube root is 2/3, and squaring gives 4/9 (about 0.444).

Decimals become easier once written as fractions: 0.04 is 1/25, 0.4 is 2/5 and 0.25 is 1/4. Converting the base and the index to fractions is usually the first step.

If aˣ = aʸ for a base a other than 0, 1 or −1, then x = y. So the method for an exponential equation is to write both sides as powers of one base and equate the indices.

Worked example 4: 3^(2x − 1) = 243

243 = 3⁵, so 2x − 1 = 5 and x = 3. Substituting back, 3⁵ = 243.

Worked example 5: different bases

Solve 2^(2x) = 4². Write 4 as 2², so the right side is 2⁴. Then 2x = 4 and x = 2. Substituting back, 2⁴ = 16 = 4².

Common bases to recognise on sight: 2 (4, 8, 16, 32, 64, 128, 256, 512, 1024), 3 (9, 27, 81, 243, 729), 5 (25, 125, 625) and 7 (49, 343, 2401). If a number does not fit any of these, check whether it is a product such as 72 = 2³ × 3².

A surd is a root that cannot be simplified to a whole number, such as √3 or ∛4. Basic square and cube roots are covered in square roots and cube roots; this section is about comparing surds with different roots.

  1. Write each surd as a fractional power: √3 = 3^(1/2), ∛4 = 4^(1/3).
  2. Take the LCM of the root orders (here 6).
  3. Raise every surd to that power. The roots disappear: (√3)⁶ = 27 and (∛4)⁶ = 16.
  4. The larger result belongs to the larger surd.

Worked example 6: √3 or ∛4?

Raised to the 6th power, they become 27 and 16. So ∛4 < √3 is true.

Worked example 7: three surds

Order √2, ∛3 and ⁴√5. The LCM of 2, 3 and 4 is 12. Raised to the 12th power they become 2⁶ = 64, 3⁴ = 81 and 5³ = 125. So ⁴√5 > ∛3 > √2, and both comparisons hold (2 of 2).

Surds of the same order multiply under one root: √a × √b = √(ab). To remove a surd from a denominator, multiply top and bottom by the conjugate, using (√a − √b)(√a + √b) = a − b.

Worked example 8: √2 × √8

√2 × √8 = √16 = 4. Neither factor is a whole number, but their product is.

Worked example 9: rationalising 1/(√3 − √2)

Multiply by (√3 + √2)/(√3 + √2). The denominator becomes 3 − 2 = 1, so the answer is √3 + √2, about 3.146.

  • Multiplying indices in a product. 2³ × 2⁴ is 2⁷, not 2¹².
  • Adding indices with different bases. 2³ × 3² cannot be combined into one power.
  • Reading a⁻ⁿ as a negative number. 2⁻³ is 1/8, which is positive.
  • Adding surds like numbers. √2 + √3 is not √5.
  • Comparing surds by the number under the root. ∛4 has the bigger radicand but is smaller than √3.

For the last digit of large powers, see unit digit of powers.

Q1. What is the value of 64^(2/3)? easy

✅ Answer: (b) 16

💡 Explanation: Take the cube root first: ∛64 = 4. Then square it: 4² = 16.

Q2. What is the value of (0.04)^(−1.5)? medium

✅ Answer: (a) 125

💡 Explanation: 0.04 = 1/25, so (1/25)^(−3/2) = 25^(3/2) = (√25)³ = 5³ = 125.

Q3. If 5^(x + 1) = 625, what is x? easy

✅ Answer: (d) 3

💡 Explanation: 625 = 5⁴, so x + 1 = 4 and x = 3.

Q4. Simplify (2³⁰ + 2³⁰ + 2³⁰ + 2³⁰) ÷ 2³¹. medium

✅ Answer: (c) 2

💡 Explanation: Four copies of 2³⁰ make 2² × 2³⁰ = 2³². Dividing by 2³¹ leaves 2¹ = 2.

Q5. What is the value of (243)^0.4? medium

✅ Answer: (d) 9

💡 Explanation: 243 = 3⁵ and 0.4 = 2/5, so (3⁵)^(2/5) = 3² = 9.

Why is any number to the power 0 equal to 1?

By the quotient rule, aⁿ ÷ aⁿ = aⁿ⁻ⁿ = a⁰. But any non-zero number divided by itself is 1, so a⁰ = 1. The rule needs a ≠ 0.

Should I take the root or the power first in a fractional index?

Either gives the same answer, but taking the root first keeps the numbers small. 81^(3/4) is easier as (⁴√81)³ = 3³ than as ⁴√(81³).

How do I compare surds with different roots?

Rewrite them with a common root order, the LCM of the root orders, and then compare the numbers under the root. For √3 and ∛4 the common order is 6: compare 3³ = 27 with 4² = 16, so √3 is larger.

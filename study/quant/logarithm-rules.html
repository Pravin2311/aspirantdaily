Logarithm Rules for Exams: Product, Quotient, Power, Change of Base, Using log 2 and log 3, and Counting Digits

A log is an exponent • log(mn), log(m/n), log(mⁿ) • Change of base • Building logs from log 2 and log 3 • Solving log equations • Digits in 2ⁿ

SSC Banking 📅 Last updated: 2026-11-03

loga b asks one question: to what power must a be raised to give b? So log₂ 8 = 3 because 2³ = 8. Every logarithm rule is an exponent rule in disguise, which is why the laws of indices are worth knowing first.

loga b = x means aˣ = b    (a > 0, a ≠ 1, b > 0)

Worked example 1: log 1000

Without a base, log means base 10. 10³ = 1,000, so log 1000 = 3.

Two values follow at once from the definition: loga 1 = 0 (because a⁰ = 1) and loga a = 1.

Worked example 2: log₇ 1

7⁰ = 1, so log₇ 1 = 0, and the same is true for every base.

RuleFormFrom the index law
Productlog(mn) = log m + log naˣ × aʸ = aˣ⁺ʸ
Quotientlog(m/n) = log m − log naˣ ÷ aʸ = aˣ⁻ʸ
Powerlog(mⁿ) = n log m(aˣ)ⁿ = aⁿˣ

These rules work in any base, as long as every log in the line uses the same base.

Worked example 3: product rule

log₂(8 × 32) = log₂ 8 + log₂ 32 = 3 + 5 = 8. Check: 8 × 32 = 256 = 2⁸.

Worked example 4: quotient rule

log₃(243/9) = 5 − 2 = 3, since 243/9 = 27 = 3³.

Worked example 5: power rule

log₂(16³) = 3 × log₂ 16 = 3 × 4 = 12.

To switch to a base you know, divide two logs in that new base:

loga b = logc b ÷ logc a    and in particular    loga b = 1 ÷ logb a

Worked example 6: log₄ 32

In base 2: log₂ 32 ÷ log₂ 4 = 5 ÷ 2 = 2.5. Check: 4^2.5 = 2⁵ = 32.

A related identity undoes a logarithm: aloga b = b, because loga b is exactly the power that turns a into b.

Worked example 7: 5 to the power log₅ 7

The exponent is the power of 5 that gives 7, so the result is 7.

Questions often give log 2 = 0.3010 and log 3 = 0.4771 and ask for the log of another number. Factorise the number into 2s, 3s and 10s, then apply the rules. log 5 is log(10/2) = 1 − 0.3010 = 0.6990.

Worked example 8: log 72

72 = 2³ × 3², so log 72 = 3(0.3010) + 2(0.4771) = 1.8572.

The same idea counts digits. A number N has (whole-number part of log N) + 1 digits.

Worked example 9: digits in 2⁵⁰

log 2⁵⁰ = 50 × 0.30103 = 15.05. The whole-number part is 15, so 2⁵⁰ has 16 digits.

Convert the log equation back to its exponent form and solve.

Worked example 10: logₓ 64 = 3

x³ = 64, so x = 4. Check that the base is positive and not 1, which it is.

When an equation has several logs, first combine them into a single log with the product and quotient rules, then convert. Always reject answers that make any log's argument zero or negative.

Worked example 11: log x + log(x − 3) = 1

Combine: log[x(x − 3)] = 1, so x(x − 3) = 10 and x² − 3x − 10 = 0. The roots are 5 and −2. x = −2 would make log x undefined, so the only answer is x = 5. Check: log 5 + log 2 = log 10 = 1.

This rejection step is where most marks are lost. A quadratic usually gives two roots, and exam options often include the invalid one.

  • Splitting a sum. log(m + n) is not log m + log n.
  • Dividing logs instead of subtracting. log(m/n) = log m − log n, not log m ÷ log n.
  • Mixing bases. Rules only combine logs with the same base.
  • Forgetting the + 1 when counting digits. log 1000 = 3, but 1,000 has 4 digits.
  • Keeping invalid solutions. Logs of zero or negative numbers are undefined.

Q1. What is log₂ 64? easy

✅ Answer: (c) 6

💡 Explanation: 64 = 2⁶, so log₂ 64 = 6. A logarithm is the exponent, not the quotient 64 ÷ 2.

Q2. What is log 5 + log 20 (base 10)? easy

✅ Answer: (a) 2

💡 Explanation: By the product rule, log 5 + log 20 = log 100 = 2.

Q3. What is log₉ 27? medium

✅ Answer: (d) 1.5

💡 Explanation: Write both as powers of 3: 27 = 3³ and 9 = 3². So log₉ 27 = 3/2 = 1.5.

Q4. If log 2 = 0.3010, what is log 8? easy

✅ Answer: (b) 0.9030

💡 Explanation: log 8 = log 2³ = 3 log 2 = 0.9030.

Q5. Using log 2 = 0.30103, how many digits does 2⁴⁰ have? medium

✅ Answer: (c) 13

💡 Explanation: log 2⁴⁰ = 40 × 0.30103 = 12.04. The digit count is the whole-number part plus 1, which is 13.

What does 'log' mean without a base?

In Indian exams, log without a base means base 10 (the common logarithm). In higher mathematics it often means base e; ln is the usual symbol for base e.

Is log(m + n) equal to log m + log n?

No. The product rule is log(mn) = log m + log n. There is no simple rule for the log of a sum.

Why can't I take the log of zero or a negative number?

No power of a positive base gives zero or a negative number, so the logarithm is undefined there. In equations, reject any solution that makes a log's argument zero or negative.

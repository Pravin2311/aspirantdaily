x + 1/x Problems: From x + 1/x to x² + 1/x², x³ + 1/x³ and Beyond

Square: subtract 2 • Cube: subtract 3 times • x − 1/x versions • From x² − kx + 1 = 0 • Special values 2, −2 and √3

SSC 📅 Last updated: 2026-10-23

SSC papers have a family of questions that start "if x + 1/x = k" and ask for x² + 1/x², x³ + 1/x³ or something higher. You never solve for x. Instead, you apply the square or cube identities to the whole expression x + 1/x. The product of x and 1/x is always 1, which is why these questions come out so neatly.

The same few rules handle the minus versions, x − 1/x, and questions disguised as quadratic equations. Learn the four formulas below and every question in this family takes one or two lines.

GivenFindFormula
x + 1/x = ax² + 1/x²a² − 2
x + 1/x = ax³ + 1/x³a³ − 3a
x − 1/x = bx² + 1/x²b² + 2
x − 1/x = bx³ − 1/x³b³ + 3b

Each comes from expanding a bracket. (x + 1/x)² = x² + 2 + 1/x², because the middle term is 2 × x × 1/x = 2. (x + 1/x)³ = x³ + 1/x³ + 3(x + 1/x), because the middle terms are 3 × x × 1/x times (x + 1/x).

Worked example 1: the square

If x + 1/x = 5, then x² + 1/x² = 25 − 2 = 23.

Worked example 2: the cube

With the same x + 1/x = 5, x³ + 1/x³ = 125 − 15 = 110.

Worked example 3: the minus version

If x − 1/x = 3, then x² + 1/x² = 9 + 2 = 11.

And x³ − 1/x³ = 27 + 9 = 36.

For fourth powers, apply the square rule twice. Treat x² as the new variable: x⁴ + 1/x⁴ = (x² + 1/x²)² − 2.

Worked example 4: x⁴ + 1/x⁴

If x + 1/x = 5, then x² + 1/x² = 23 and x⁴ + 1/x⁴ = 23² − 2 = 527.

For a sixth power, either square x³ + 1/x³ and subtract 2, or cube x² + 1/x² and subtract three times it. Both routes give the same answer, which makes a handy check.

Going backwards is also common. Given x² + 1/x², add 2 and take the square root to recover x + 1/x.

Worked example 5: from the square back to the cube

If x² + 1/x² = 7 and x > 0, then (x + 1/x)² = 9, so x + 1/x = 3. Then x³ + 1/x³ = 27 − 9 = 18.

An equation of the form x² − kx + 1 = 0 is an x + 1/x question. Divide every term by x to get x − k + 1/x = 0, so x + 1/x = k.

Worked example 6: x² − 6x + 1 = 0

Dividing by x gives x + 1/x = 6, so x² + 1/x² = 36 − 2 = 34.

Two special values make every power easy. If x + 1/x = 2, then x = 1, so xⁿ + 1/xⁿ = 2 for every n. If x + 1/x = −2, then x = −1, and the answer alternates between −2 for odd n and 2 for even n.

Worked example 7: x + 1/x = 2

x = 1, so x¹⁰⁰ + 1/x¹⁰⁰ = 1 + 1 = 2.

Worked example 8: x + 1/x = √3

x³ + 1/x³ = (√3)³ − 3√3 = 3√3 − 3√3 = 0. Questions then often ask for x⁶, which works out to −1 because x³ + 1/x³ = 0 means x⁶ + 1 = 0.

  • ✘ Subtracting 2 for x − 1/x. With the minus version, add 2.
  • ✘ Cubing without the −3a term: x³ + 1/x³ is not simply a³.
  • ✘ Forgetting to divide by x when the question is a quadratic.
  • ✘ Taking only the positive square root when the sign of x is not given.

Q1. If x + 1/x = 4, what is x² + 1/x²? easy

✅ Answer: (c) 14

💡 Explanation: Square both sides: x² + 2 + 1/x² = 16, so x² + 1/x² = 16 − 2 = 14.

Q2. If x + 1/x = 3, what is x³ + 1/x³? easy

✅ Answer: (a) 18

💡 Explanation: x³ + 1/x³ = (x + 1/x)³ − 3(x + 1/x) = 27 − 9 = 18.

Q3. If x − 1/x = 5, what is x² + 1/x²? medium

✅ Answer: (d) 27

💡 Explanation: Squaring x − 1/x gives x² − 2 + 1/x² = 25, so x² + 1/x² = 25 + 2 = 27. With a minus sign inside, add 2 instead of subtracting it.

Q4. If x² − 4x + 1 = 0, what is x³ + 1/x³? medium

✅ Answer: (b) 52

💡 Explanation: Divide the equation by x: x − 4 + 1/x = 0, so x + 1/x = 4. Then x³ + 1/x³ = 64 − 3 × 4 = 52.

Q5. If x² + 1/x² = 18, what is x⁴ + 1/x⁴? medium

✅ Answer: (c) 322

💡 Explanation: Treat x² as the variable and use the square rule again: x⁴ + 1/x⁴ = (x² + 1/x²)² − 2 = 324 − 2 = 322.

Q6. If x + 1/x = 2, what is x⁵⁰ + 1/x⁵⁰? easy

✅ Answer: (a) 2

💡 Explanation: x + 1/x = 2 gives x² − 2x + 1 = 0, that is (x − 1)² = 0, so x = 1. Then x⁵⁰ + 1/x⁵⁰ = 1 + 1 = 2.

Can x + 1/x be any number?

For real x, x + 1/x is never between −2 and 2. It equals 2 only at x = 1 and −2 only at x = −1. If a question gives a value such as 1 or √3, x is not real, but the identities still give the right answer for the expression asked.

How do I find x + 1/x from x² + 1/x²?

Add 2 and take the square root: (x + 1/x)² = x² + 1/x² + 2. If the question says x is positive, take the positive root. Otherwise both signs are possible, and the answer may come out as plus or minus.

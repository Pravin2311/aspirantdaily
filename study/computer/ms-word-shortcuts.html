  • Ctrl+F opens the Navigation pane to search the document.
  • Ctrl+H opens the Replace dialog box to find and replace text, formatting or special items. "H" is not Help.
  • Ctrl+G or F5 opens Go To, which jumps to a page, bookmark, footnote, table, comment or graphic.
  • Ctrl+Home and Ctrl+End jump to the beginning and end of the document.
  • Ctrl+Backspace and Ctrl+Delete delete a whole word to the left or right.
  • Ctrl+Alt+I switches to print preview; Ctrl+F2 also shows the print preview area.

  • Ctrl+E vs Ctrl+J: E centres, J justifies. Left and right are the easy ones, L and R.
  • Ctrl+H vs Ctrl+F: H is find and replace, F is find only.
  • Shift+Enter vs Ctrl+Enter: Shift+Enter breaks the line; Ctrl+Enter starts a new page.
  • F12 vs Shift+F12: F12 opens Save As; Shift+F12 simply saves, like Ctrl+S.
  • Ctrl+W vs Alt+F4: Ctrl+W (or Ctrl+F4) closes the document; Alt+F4 closes Word itself.
  • F7 vs Shift+F7: spelling and grammar vs Thesaurus.
  • Ctrl+Y vs Ctrl+Z: Y redoes, Z undoes.

Q1. In MS Word for Windows, Ctrl+E is used to: easy

✅ Answer: (a) Centre the paragraph

💡 Explanation: Microsoft lists Ctrl+E as 'Center the paragraph'. Ctrl+J justifies, Ctrl+L aligns left and Ctrl+R aligns right.

Q2. Which key opens the Editor pane to check spelling and grammar? easy

✅ Answer: (c) F7

💡 Explanation: F7 displays the Editor task pane for spelling and grammar. Shift+F7 opens the Thesaurus.

Q3. To insert a page break in Word, press: medium

✅ Answer: (d) Ctrl+Enter

💡 Explanation: Ctrl+Enter inserts a page break. Shift+Enter is a line break and Ctrl+Shift+Enter is a column break.

Q4. Ctrl+H in MS Word opens: easy

✅ Answer: (b) The Replace dialog box

💡 Explanation: Ctrl+H displays the Replace dialog box to find and replace text. Ctrl+K inserts a hyperlink and F1 shows help.

Q5. Which shortcut displays the Save As dialog box? medium

✅ Answer: (c) F12

💡 Explanation: F12 alone displays Save As. Shift+F12 and Ctrl+S save the document, and Ctrl+F12 opens the Open dialog box.

What are the most asked ms word shortcut keys in exams?

Alignment (Ctrl+E, J, L, R), Ctrl+H for replace, Ctrl+K for hyperlink, Ctrl+Enter for page break, F7 for spelling, F12 for Save As and Shift+F3 for changing case come up most often.

What is the difference between Ctrl+G and F5 in Word?

There is no difference in result. Microsoft lists both: Ctrl+G and F5 each open the Go To dialog box, which jumps to a page, bookmark, footnote, table, comment or graphic.

Do these shortcuts work on a Mac?

Not always. This list is for Word for Windows. Microsoft notes that many Ctrl shortcuts also work with the Control key in Word for Mac, but not all, and Mac often uses the Command key instead.

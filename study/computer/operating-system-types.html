Operating System: Its Four Functions, Five Types of User Interface, and Where It Sits Among System Software

OS as resource manager • Process, memory, file and device management • Command, GUI, touch, voice and gesture interfaces • Utilities and device drivers • FOSS, freeware, proprietary

SSC Bank Railway 📅 Last updated: 2026-11-01

An operating system (OS) is the system software that runs the computer. NCERT calls it the most basic system software, because no other software can work without it. Popular examples are Windows, Linux, Macintosh, Ubuntu, Fedora, Android and iOS.

NCERT describes the OS as a resource manager. It manages the hardware: the CPU, RAM, disk, network and input-output devices. It also controls application software and device drivers, looks after system security, and handles access by different users.

The OS has two main objectives:

  1. Running programs: it loads a program into memory and gives it the CPU. When several programs need to run, it decides their order.
  2. Giving the user an interface: a part of the OS takes the user's commands or inputs and passes them on for processing.

A computer can work without application software. If no word processor is installed, you can still use the computer. It cannot work without system software such as the OS.

FunctionWhat it managesKey points
Process managementPrograms that are running (processes)A task in execution is a process. Sharing the CPU among processes is the OS's most important service. This function also allocates resources and lets processes exchange information.
Memory managementMain memory (RAM)Gives memory to running processes and takes it back when they finish, without disturbing other processes. Tracks every location as free or occupied.
File managementSecondary storageCreates, updates, deletes and protects files, and stops users from opening files that others have not shared with them.
Device managementInput-output devicesWorks through device drivers, lets devices be configured, and limits device access to authorised users, software and hardware.

An easy trap: memory management is about main memory, while file management is about secondary storage such as the hard disk. Questions often swap the two. The system monitor that shows running processes can be opened with Ctrl+Alt+Delete on some systems.

Graphical (GUI)Icons, menus and windows, using a mouse and keyboardMicrosoft Windows, Ubuntu, Fedora, Macintosh

NCERT notes that gesture control is developing fast, with promising uses in gaming and medicine.

System software works directly with the hardware to give the computer its basic functions. NCERT names three kinds:

  • Operating system: runs the computer and manages the other software.
  • System utilities: maintain and configure the computer. Some come with the OS, such as disk defragmentation, formatting and system restore. Others are installed separately to improve performance.
  • Device drivers: each one is the interface between a particular device and the OS. Like a translator, it hides the hardware details. Drivers exist because the OS alone cannot operate every new device that is added to a computer.

Programming tools, such as translators and code editors, and application software, such as office suites, run on top of the system software.

Computers understand only machine language (1s and 0s), but people write programs in assembly or high-level languages. Code written in these languages is called source code. A translator converts it into machine-understandable object code. NCERT names three translators:

TranslatorConvertsHow it works
AssemblerAssembly language to machine languageEach assembler understands one microprocessor's instruction set, so its machine code is not portable
CompilerHigh-level language to machine codeTranslates the whole program; once it is translated, the compiler is no longer needed
InterpreterHigh-level language, line by lineTranslates and runs one line at a time, so it is needed every time the program runs

Low-level languages, meaning machine and assembly language, are machine-dependent. High-level languages are machine-independent and use English-like statements, which is why they need translators. Translators and code editors are programming tools. They sit between system software and the application software that end users run.

TypeMeaningExamples in NCERT
Free and Open Source Software (FOSS)The software and its source code are freely available, so others can improve itUbuntu
FreewareFree to use, but the source code may not be availableSkype, Adobe Reader

So Windows and Ubuntu are both operating systems, but Windows is proprietary and Ubuntu is FOSS. This pairing is a common exam question. For computer history and generations, see history of computers.

Q1. Which of these is NOT system software? easy

✅ Answer: (d) Spreadsheet program

💡 Explanation: A spreadsheet is application software. NCERT lists operating systems, system utilities such as defragmenters, and device drivers as system software.

Q2. MS-DOS is an example of an operating system with which kind of interface? easy

✅ Answer: (a) Command-based

💡 Explanation: NCERT gives MS-DOS and Unix as examples of command-based interfaces, where the user types commands on the keyboard.

Q3. Which OS function manages files stored in secondary memory? easy

✅ Answer: (c) File management

💡 Explanation: File management handles creating, updating, deleting and protecting files in secondary storage. Memory management handles main memory.

Q4. According to NCERT, the most important service of an operating system is: medium

✅ Answer: (b) Allocating the CPU among processes

💡 Explanation: NCERT says the CPU is the main resource, so allocating it among processes is the most important service of the OS.

Q5. Software whose source code is freely available for anyone to improve, such as Ubuntu, is called: medium

✅ Answer: (c) Free and Open Source Software (FOSS)

💡 Explanation: FOSS shares both the software and its source code. Freeware is free to use, but its source code may not be available.

Why is the operating system called a resource manager?

It shares the computer's resources, such as the CPU, main memory, storage and input-output devices, among running programs, so that each is used well and the system does not slow down.

Can a computer work without an operating system?

Not for ordinary use. NCERT explains that a computer can work without application software such as a word processor, but it cannot work without system software like the operating system.

What is the difference between a device driver and a utility?

A device driver lets the operating system talk to one particular device, such as a printer. A utility maintains or configures the system as a whole, for example by defragmenting or formatting a disk.

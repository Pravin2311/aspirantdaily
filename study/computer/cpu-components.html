CPU Components: ALU, Control Unit and Registers, the Machine Cycle, System Bus and Microprocessor Generations

ALU vs CU vs registers • Fetch-decode-execute • Data, address, control bus • Cache • Five microprocessor generations • Microcontrollers

SSC Banking Railways 📅 Last updated: 2026-11-07

NCERT's Class 11 Computer Science textbook (Chapter 1, "Computer System") describes the Central Processing Unit (CPU) as the electronic circuitry that carries out the actual processing. It is usually called the brain of the computer, and is also commonly called the processor.

Physically, a CPU sits on one or more microchips called integrated circuits (ICs), which are made of semiconductor materials.

A computer system mainly comprises four parts:

  • the CPU;
  • memory;
  • input/output devices;
  • storage devices.

The CPU receives instructions and data through programs. It fetches the program and data from memory, performs arithmetic and logic operations as instructed, and stores the result back in memory.

ComponentWhat it doesExam keyword
Arithmetic Logic Unit (ALU)Performs all the arithmetic and logic operations an instruction calls forCalculation and comparison
Control Unit (CU)Controls sequential instruction execution, interprets instructions, and guides data flow through memory, the ALU and input/output devicesCoordinator or "manager"; does no calculation itself
RegistersThe CPU's local memory for data, instructions and intermediate results during processing; part of the CPU chip, limited in size and numberFastest storage in the computer

NCERT puts it this way: other than the registers, the CPU has two main components, the ALU and the CU. Common registers named in exam guides include:

  • the program counter, which holds the address of the next instruction;
  • the instruction register, which holds the current instruction;
  • the accumulator, which holds ALU results;
  • the memory address register and the memory data register.

Every instruction passes through the same loop:

  1. Fetch: the CPU places the instruction's memory address on the address bus and reads the instruction from main memory.
  2. Decode: the Control Unit interprets what the instruction asks for.
  3. Execute: the ALU carries out the arithmetic or logic operation, with operands held in registers.
  4. Store: the result is written back to a register or to memory.

The clock sets the pace of this loop. NCERT explains that the internal clock generates pulses at regular intervals, and the clock speed indicates how fast the computer can execute instructions. Clock speed was once measured in hertz and kilohertz; it is now measured in gigahertz, or billions of pulses per second.

Components exchange data over physical wires called a bus. NCERT names three types, which together make up the system bus:

BusCarriesDirection
Data busData between componentsBidirectional
Address busThe memory address the CPU wants to read from or write toUnidirectional
Control busControl signals, such as read or writeUnidirectional
  • Read: the CPU specifies the address, and a dedicated piece of hardware called the memory controller places the data on the data bus.
  • Write: the CPU places the data on the data bus, and it is written to the address given on the address bus.

Because the CPU interacts directly only with main memory, anything from an input device or the hard disk must first be placed in main memory before it can be processed.

Cache sits between the CPU and primary memory. It is a very high-speed memory holding copies of frequently accessed data. The CPU checks the cache first and goes to main memory only if the data is not found there.

A CPU built on a single microchip is a microprocessor. Today almost all CPUs are microprocessors, so the two terms are used synonymously. NCERT's Table 1.2 traces their generations:

GenerationEraChipWord sizeMax memoryExamples

Second1974–78LSI8 bit1 MBMotorola 6800, Intel 8085

NCERT defines the key specifications:

  • Word size is the maximum number of bits processed at a time. Today the minimum is 16 bits and the maximum 64 bits.
  • Cores are the basic computation units. CPUs with two, four and eight cores are dual-core, quad-core and octa-core processors.

A microcontroller puts a CPU, a fixed amount of RAM, ROM and other peripherals on a single chip. A microprocessor has only the CPU on the chip. Microcontrollers are designed for specific tasks, so they are smaller and cheaper, and they are embedded inside other devices.

NCERT's examples include the keyboard, mouse, washing machine, digital camera, pendrive, remote controller and microwave. In a fully automatic washing machine, the microcontroller runs the whole washing cycle without human intervention.

Suppose a program says "add the numbers stored at two memory locations and save the total". The parts of the CPU share the work like this:

  1. The Control Unit sends each location's address on the address bus, with a read signal on the control bus.
  2. The memory controller places each number on the data bus, and the numbers land in registers.
  3. The ALU adds them.
  4. The Control Unit then sends the destination address and a write signal, and the total travels back over the data bus into memory.

Every step happens on a tick of the clock, which is why a higher clock speed means more instructions per second.

  • The Control Unit does not calculate. Arithmetic and comparisons are the ALU's job.
  • Registers are faster than cache, and cache is faster than RAM. The CPU cannot read secondary storage directly.
  • The data bus is bidirectional; the address and control buses are one-way.
  • "CPU" and "microprocessor" are used synonymously today. A microcontroller is a whole small computer on a chip.

Q1. Which part of the CPU performs arithmetic and logic operations? easy

✅ Answer: (a) Arithmetic Logic Unit

💡 Explanation: NCERT says the ALU performs all the arithmetic and logic operations needed by program instructions.

Q2. Which component interprets instructions and guides data flow? easy

✅ Answer: (b) Control Unit

💡 Explanation: The Control Unit controls sequential execution, interprets instructions and guides data flow through the system.

Q3. The CPU's own small, fastest local memory is the: easy

✅ Answer: (c) Register

💡 Explanation: NCERT calls registers the CPU's local memory, part of the CPU chip and limited in size and number.

Q4. Which bus is bidirectional? medium

✅ Answer: (d) Data bus

💡 Explanation: NCERT says the data bus is bidirectional while the control and address buses are unidirectional.

Q5. The address of the memory location the CPU wants to access travels on the: medium

✅ Answer: (a) Address bus

💡 Explanation: The address bus carries addresses between the CPU and main memory for each read or write.

Q6. A chip with CPU, RAM, ROM and peripherals together is a: medium

✅ Answer: (b) Microcontroller

💡 Explanation: NCERT defines a microcontroller as CPU, fixed RAM, ROM and peripherals embedded on a single chip.

Q7. A CPU with eight cores is called: easy

✅ Answer: (c) Octa-core

💡 Explanation: NCERT says two, four and eight cores make dual-core, quad-core and octa-core processors.

Q8. According to NCERT's table, the Intel 8086 belongs to which microprocessor generation? hard

✅ Answer: (d) Third

💡 Explanation: Table 1.2 places the Intel 8086 in the third generation, 1979-80, VLSI, 16-bit word size.

What are the main parts of a CPU?

NCERT names the Arithmetic Logic Unit, the Control Unit and the registers. The ALU calculates, the CU directs execution and data flow, and registers hold working data.

What is the difference between a microprocessor and a microcontroller?

A microprocessor has only the CPU on its chip. A microcontroller embeds a CPU, RAM, ROM and peripherals on one chip for a specific task, like a washing machine.

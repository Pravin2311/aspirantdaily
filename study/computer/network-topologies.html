Network Topology Types: Bus, Star, Ring, Mesh and Tree Compared

What topology means • Bus • Ring • Star • Mesh and its cable formula • Tree or hybrid • Comparison table

SSC Banking 📅 Last updated: 2026-10-29

A network's topology is the way its computers and other devices are arranged and connected. The same handful of computers can be wired in very different shapes, and the shape decides three things exam questions ask about: how much cable is needed, what it costs, and what fails when one cable or device breaks.

Five layouts are standard: bus, ring, star, mesh and tree (also called hybrid). The first four are the basic shapes; tree combines them.

In a bus topology, every device connects to one shared cable, the bus or backbone. A node puts its data onto the bus, and the data travels along the whole length of the cable in both directions, so any node can receive it.

Strengths: it needs the least cable and is cheap and easy to maintain. Weaknesses: all nodes share one wire, so it is considered less secure and less reliable.

In a ring topology, each node connects to exactly two others, one on either side, so the connections close into a ring. The link is unidirectional: data travels in one direction only, clockwise or anticlockwise, passing from node to node until it arrives.

A ring uses about as many cables as there are nodes. Like the bus, it is considered less secure and less reliable.

In a star topology, every device has its own cable to a central node, which is a networking device such as a hub or a switch. It is effective and fast, because each device talks directly to the centre.

The failure rules are the most tested point. If one ordinary device or its cable fails, the rest of the network keeps working. But if the central device fails, the whole network can go down, because every message passes through it.

The centre can behave in two ways. A broadcasting device, like a hub, sends data to all nodes. A unicast device, like a switch, identifies the destination and forwards data to that node only.

In a full mesh, every device connects to every other device. A mesh can handle a lot of traffic, because many pairs of nodes can send at the same time. It is reliable: if one node goes down, the others keep communicating over their own links. It is also more secure, since each cable carries only the data between its two nodes. The price is complex wiring, high cable cost and many links that sit unused much of the time.

The number of cables in a full mesh of n nodes is n(n − 1)/2. Each node links to the other n − 1 nodes, and the division by 2 stops each cable being counted twice, once from each end.

Worked example 1: five computers

n = 5: 5 × 4 ÷ 2 = 10 cables.

Worked example 2: eight computers

n = 8: 8 × 7 ÷ 2 = 28 cables.

Worked example 3: ports on each computer

In the same eight-node mesh, each computer connects to every other one, so it needs 8 − 1 = 7 ports.

Worked example 4: mesh against star

A star of 8 computers needs 8 cables, one to each device from the centre. The mesh needs 28, so it uses 20 more cables. The gap widens quickly as n grows.

A tree or hybrid topology is hierarchical. It has several branches, and each branch can be built from one or more basic topologies: star, ring or bus. A common example is several star-shaped LANs hanging off one bus. Data from a source first reaches a central device and then passes down the branches.

Tree layouts are usually found in WANs, where many LANs of different shapes are joined. They inherit both the strengths and the weak points of the shapes they combine.

  • ✘ Saying a star survives any failure. It fails as a whole if the centre fails.
  • ✘ Calling a ring two-way. In the textbook ring, data moves in one direction.
  • ✘ Calling a tree a separate basic shape. It is a combination of the basic shapes.

Q1. In which topology is every device connected to a single central device? easy

✅ Answer: (c) Star

💡 Explanation: In a star topology each device has its own cable to a central hub or switch. In a bus they share one cable; in a ring each links to two neighbours.

Q2. Which topology uses a single shared backbone cable? easy

✅ Answer: (a) Bus

💡 Explanation: A bus topology connects every node to one backbone wire called the bus. It is cheap to lay but less reliable.

Q3. Which topology has the highest cabling cost but stays working even if one link fails? easy

✅ Answer: (d) Mesh

💡 Explanation: A mesh connects every device to every other, so there is always another path, but it needs the most cables and the most complex wiring.

Q4. How many cables does a fully connected mesh of 6 computers need? medium

✅ Answer: (b) 15

💡 Explanation: Use n(n − 1)/2 with n = 6: 6 × 5 ÷ 2 = 15. Thirty is the trap of forgetting to halve, since each cable joins two computers.

Q5. In a star network, what happens if the central switch fails? medium

✅ Answer: (a) The whole network can go down

💡 Explanation: Every device reaches the others only through the central device, so its failure can bring down the complete network. Failure of one ordinary device affects only that device.

Q6. A company joins several star-shaped office LANs to one backbone cable. This layout is: medium

✅ Answer: (c) A tree or hybrid topology

💡 Explanation: Combining basic topologies in a hierarchy, here stars hanging off a bus, makes a tree or hybrid topology. Such layouts are common when many LANs are connected.

Which network topology is most common today?

Home and office wired LANs are usually built as a star around a switch, and larger networks join many such stars into a tree. The site cannot give a market share figure, so treat this as the typical layout rather than a statistic.

Is topology the same as the physical cabling?

Topology describes how devices are arranged and linked. Exam questions mean the physical layout of cables and devices, which is what this page covers. Networking courses also discuss logical topology, the path data actually takes, which can differ from the cabling.

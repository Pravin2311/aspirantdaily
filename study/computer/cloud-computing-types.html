Cloud Computing: IaaS, PaaS and SaaS With Examples, the Four Deployment Models, Five Characteristics, and Cloud vs Grid

Services over the Internet, pay per use • IaaS: infrastructure • PaaS: a platform to deploy apps • SaaS: ready software • Public, private, community, hybrid • Five NIST characteristics • Cloud vs grid

SSC Banking 📅 Last updated: 2026-11-04

In cloud computing, computer services are delivered over the Internet instead of running on your own machine. NCERT lists what can be delivered: software, hardware such as servers, databases and storage. Companies called cloud service providers supply these resources and usually charge per use, much as we pay for electricity by the unit.

You already use the cloud if you back up photos online or host a website. The main benefit is that a user can run a big application or process a lot of data without owning the storage or processing power, as long as there is an Internet connection.

The US standards body NIST gives the definition most textbooks follow. Its model has five essential characteristics, three service models and four deployment models. Exams ask about all three groups, so this page covers each.

NCERT suggests thinking of the cloud as "everything as a service". The three standard service models differ in how much the provider manages for you.

ModelWhat you getWhat you still controlExample in NCERT
IaaS (Infrastructure as a Service)Servers, virtual machines, storage and backup, network parts, operating systemsThe operating system, storage and the applications you deployRenting remote hardware to configure and run your own software
PaaS (Platform as a Service)A ready environment to develop, test and deliver applicationsYour deployed application and its settingsA pre-configured Apache server with MySQL and Python installed
SaaS (Software as a Service)Finished application software, usually by licence or subscriptionOnly limited settings inside the applicationGoogle Docs, Microsoft Office 365, Dropbox

A useful way to place IaaS, PaaS and SaaS examples is to ask who installs what. With IaaS you get bare infrastructure and install the operating system and software yourself. With PaaS the platform is installed for you and you only upload your application. With SaaS there is nothing to install: you open the software and use it.

In all three models the user pays as per usage. NCERT points out that this removes the need for a large investment upfront, which helps new or growing organisations.

In India, the Government's cloud initiative, GI Cloud, is named MeghRaj. This name is a frequent one-line question in banking and SSC computer awareness papers.

Service models describe what you get. Deployment models describe who the cloud is for. NIST defines four:

Deployment modelWho uses itWhere it can be
Private cloudOne organization only, which may have several unitsOn or off the organization's premises
Community cloudA group of organizations with shared concerns, such as security or compliance needsOn or off premises
Public cloudOpen use by the general publicOn the cloud provider's premises
Hybrid cloudA combination of two or more of the above that stay distinct but are linkedMixed

A private cloud may be owned and run by the organization itself, by a third party, or by both. In a hybrid cloud, the separate clouds are bound together by technology that lets data and applications move between them. NIST's example is "cloud bursting", where extra load spills from one cloud to another.

NIST says a service counts as cloud computing when it has these five features:

  1. On-demand self-service: the user can get computing capacity, such as server time or storage, automatically, without asking a person at the provider.
  2. Broad network access: the service is reached over the network from phones, tablets, laptops and workstations.
  3. Resource pooling: the provider's resources serve many customers at once and are assigned according to demand. Customers usually do not know the exact location of their resources.
  4. Rapid elasticity: capacity can grow or shrink quickly with demand, sometimes automatically. To the user it can seem unlimited.
  5. Measured service: usage is metered, monitored and reported, which is what makes pay-per-use billing possible.

A quick memory aid is the order of the list: self-service, network, pooling, elasticity, metering. A question that lists four of these and one unrelated term, such as "grid" or "blockchain", is asking you to spot the odd one out.

NCERT places grid computing next to the cloud because the two are often confused. A grid is a network of computers in different places, which may be of different kinds. Each computer is called a node. The nodes come together to solve one large task, acting like a virtual supercomputer.

The cloud focuses on providing services to many users; a grid is application-specific. In IaaS a provider rents infrastructure to users, while in a grid many nodes join to solve a common problem. Grids come in two types: a data grid, which manages large distributed data, and a CPU or processor grid, which splits processing across nodes. Building a grid needs middleware; NCERT names the open-source Globus toolkit.

Q1. Editing a document online in Google Docs or Microsoft Office 365 is an example of which cloud service model? easy

✅ Answer: (c) SaaS

💡 Explanation: These are ready-to-use applications delivered over the Internet, which NCERT gives as examples of Software as a Service.

Q2. A developer rents a pre-configured server with MySQL and Python already installed and only uploads the application. Which service is this? medium

✅ Answer: (a) PaaS

💡 Explanation: PaaS gives a ready platform to deploy and run applications without setting up the infrastructure. This is NCERT's own PaaS example.

Q3. According to NIST, a cloud that is a composition of two or more distinct cloud infrastructures is a: easy

✅ Answer: (d) Hybrid cloud

💡 Explanation: NIST defines a hybrid cloud as two or more distinct infrastructures (private, community or public) bound together by technology that allows data and application portability.

Q4. Which of these is NOT one of NIST's five essential characteristics of cloud computing? medium

✅ Answer: (b) Data grid

💡 Explanation: The five characteristics are on-demand self-service, broad network access, resource pooling, rapid elasticity and measured service. A data grid is a type of grid computing.

Q5. What is the Government of India's cloud initiative called? easy

✅ Answer: (b) MeghRaj

💡 Explanation: NCERT notes that the GI Cloud initiative has been named MeghRaj.

What is the easiest way to remember IaaS, PaaS and SaaS?

Ask what you still manage yourself. In IaaS you manage the operating system and everything above it. In PaaS you manage only your application. In SaaS you manage nothing but your own use of the software.

Is cloud storage like Google Drive IaaS or SaaS?

For an ordinary user it is SaaS, because you use a finished application through a browser or app. NCERT lists Dropbox, a similar storage service, among its SaaS examples.

How is grid computing different from cloud computing?

A cloud provider rents services to many users. A grid links many computers so they can work together as one virtual supercomputer on a single large task.

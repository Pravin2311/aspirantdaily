  • ASCII vs ISCII: the "I" in ISCII is Indian, not International.
  • Network sizes: PAN is smaller than LAN, then MAN, then WAN. The Internet is the largest WAN.
  • Email protocols: SMTP is for sending mail, FTP for files and HTTP for web pages.
  • Addresses: a MAC address belongs to the network card, while an IP address is assigned on a network. IPv4 addresses are 32 bits and IPv6 addresses 128 bits.
  • Cloud models: SaaS, PaaS and IaaS are cloud service models, not programming languages.

Q1. What is the full form of VLSI? easy

✅ Answer: (a) Very Large Scale Integration

💡 Explanation: NCERT's Class 11 Computer System chapter expands VLSI as Very Large Scale Integration, the chip stage after LSI.

Q2. ISCII stands for: medium

✅ Answer: (b) Indian Script Code for Information Interchange

💡 Explanation: NCERT's encoding chapter expands ISCII as Indian Script Code for Information Interchange, developed for Indian scripts.

Q3. NIC in networking stands for: easy

✅ Answer: (c) Network Interface Card

💡 Explanation: NCERT says the Ethernet card is also known as the Network Interface Card, a network adapter for wired networks.

Q4. Which protocol is used to send email? easy

✅ Answer: (d) SMTP

💡 Explanation: NCERT lists SMTP, the Simple Mail Transfer Protocol, as the protocol used for transferring email messages.

Q5. SaaS, PaaS and IaaS are models of: medium

✅ Answer: (a) Cloud computing services

💡 Explanation: NCERT's Emerging Trends chapter names Software, Platform and Infrastructure as a Service as cloud service models.

Q6. An IPv6 address is how many bits long? medium

✅ Answer: (b) 128

💡 Explanation: NCERT says a 128-bit address called IP version 6 was proposed because 32-bit IPv4 allowed only about 4.3 billion addresses.

Q7. DDoS stands for: easy

✅ Answer: (c) Distributed Denial of Service

💡 Explanation: NCERT's Security Aspects chapter expands DDoS as Distributed Denial of Service, an attack from many sources.

Q8. RJ45 is a connector with how many pins? hard

✅ Answer: (d) Eight

💡 Explanation: NCERT describes RJ 45, Registered Jack-45, as an eight-pin connector used with Ethernet cables for networking.

What is the full form of WWW and who developed HTML?

WWW is the World Wide Web. NCERT's networks chapter notes that Tim Berners-Lee at CERN developed HTML and URL, which gave rise to the web.

What is the difference between ASCII and ISCII?

ASCII is the American Standard Code for Information Interchange for English characters; ISCII, the Indian Script Code for Information Interchange, encodes Indian scripts.

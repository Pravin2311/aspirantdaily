Internet Terms for Computer Awareness: Internet vs Web, HTML, URL, HTTP, DNS, IP and MAC Addresses and Cookies, From NCERT

Internet vs web • Berners-Lee's three technologies • How a page loads • IP, MAC, domain names • DNS root servers • HTTPS • Cookies • Exam traps

NCERT's Class 12 Computer Science text (Chapter 10, "Computer Networks") notes that many people confuse the web with the Internet. They are different things:

  • The Internet is the global network of computing devices: desktops, laptops, servers, phones, printers, routers, switches, gateways and smart appliances.
  • The World Wide Web is the interlinked collection of web pages on those computers, accessed over the Internet. NCERT calls it "an ocean of information" made of trillions of interlinked web pages and resources.

How you reach it: your computer connects to a modem by cable or Wi-Fi. The modem connects to a local Internet Service Provider (ISP). ISPs join into regional networks and then national ones, and these country-wise networks form the Internet backbone.

Sir Tim Berners-Lee, a British computer scientist, invented the World Wide Web in 1990. He did it by defining three technologies.

TermFull formWhat it does (NCERT)
HTMLHyperText Markup LanguageDesigns standardised web pages readable on any computer; the basic structure of every web page
URI / URLUniform Resource Identifier / LocatorA unique address for each resource on the web; also called a web address
HTTPHyperText Transfer ProtocolRules for retrieving linked web pages; HTTPS is the more secure version

A URL is more than a domain name. In NCERT's example, http://www.ncert.nic.in/textbook/textbook.htm is the URL, and www.ncert.nic.in is only its domain-name part.

Hypertext is a document containing images or text that link to another document or text.

  1. A web page is written in HTML and stored on a web server, where it can be reached through its URL.
  2. You type the URL into a web browser, which is the client.
  3. The browser needs the server's IP address, so HTTP asks a DNS server for the IP address that matches the domain name. NCERT calls this step domain name resolution.
  4. HTTP, a request-response (client-server) protocol that runs over TCP, then sends a request to that server. The server's response delivers the page to your browser.

NCERT adds that Tim Berners-Lee led the development of HTTP at CERN in 1989, with the IETF and W3C.

TermKey facts (NCERT)
IP addressA unique address for each node on a network using the Internet Protocol. It can change if the node moves to another network
IPv432-bit, written as four numbers from 0 to 255 separated by periods, e.g. 192.168.0.178. Gives just under 4.3 billion addresses
IPv6128-bit, written as eight groups of hexadecimal numbers separated by colons
MAC addressMedia Access Control, the physical or hardware address. It is engraved on the NIC at manufacture and is permanent
Domain nameA name given to a server in place of its IP address, like a phonebook entry, e.g. ncert.nic.in
DNS root servers13 servers named A to M: ten in the US and one each in London, Stockholm and Japan. IANA keeps the list

NCERT's Chapter 12, "Security Aspects", explains that HTTP and HTTPS both set the rules for how data moves over the web between browsers and servers. HTTP sends information as it is, without scrambling it. NCERT advises always looking for "https://" before entering banking or other sensitive details.

A cookie is a small file or data packet that a website stores on the client's computer. It can be edited only by the website that created it. Websites use cookies to store browsing information, such as:

  • items in a shopping cart;
  • language preference;
  • recently viewed pages.

The term comes from the "magic cookie" of Unix programmers.

  • Session cookies track the current session and can end it after a time-out, as on banking sites.
  • Authentication cookies check whether you are already logged in.
  • Zombie cookies get recreated after being deleted. Some malware disguises itself as "supercookies".
  • The web (1990, Berners-Lee) is not the Internet. The web runs on top of the Internet.
  • A MAC address is permanent. An IP address can change.
  • IPv4 is 32-bit and dotted decimal. IPv6 is 128-bit and colon-separated hexadecimal.
  • Converting a domain name to an IP address is domain name resolution, and a DNS server does it.

What is the difference between the Internet and the web?

The Internet is the global network of connected devices. The web is the collection of interlinked web pages on those computers that you access over the Internet.

What does a DNS server do?

It converts the domain name you type, such as ncert.nic.in, into the server's IP address so the browser can fetch the page. NCERT calls this domain name resolution.

Number Analogy Reasoning: Squares, Cubes, n(n + 1), Digit Rules and Primes in a : b :: c : ?

Test order: ×, square, cube • n² ± 1 and n³ ± 1 • n(n + 1) and n³ − n • Digit sum and reversal • Consecutive primes • Spotting two-rule traps

SSC Railway 📅 Last updated: 2026-11-02

A number analogy gives a pair related by a hidden rule, then a third number, and asks for the fourth: a : b :: c : ?. Your job is to name the rule that turns a into b, then apply exactly the same rule to c.

Most exam rules come from a short list. Testing them in a fixed order is faster than guessing:

  1. Simple multiple: is b a fixed multiple of a?
  2. Square or cube: is b equal to a² or a³?
  3. Square or cube plus or minus 1 (or another small number).
  4. Products of neighbours: n(n + 1), or (n − 1) × n × (n + 1) = n³ − n.
  5. Digit rules: digit sum, digit product or reversed digits.
  6. Primes: the next prime, or the prime at a given position.

Having squares and cubes at your fingertips makes most of these instant; see the squares and cubes table.

Worked example 1: a plain square

7 : 49 :: 9 : ? 49 = 7², so the answer is 9² = 81.

Worked example 2: cube plus one

3 : 28 :: 4 : ? 3³ = 27 and 28 is one more. Applying the same rule, 4³ + 1 = 65.

When b is just above or below a square or cube, test the nearest power first. Numbers such as 26, 28, 63, 65, 124 and 126 are giveaways for cubes ± 1.

A quick size check also helps. If b is roughly a times a, think squares; if b is far larger, around a times a times a, think cubes. If b is about twice or three times a, look for a simple multiple or a small addition instead of a power.

Two patterns are easy to miss because they do not look like powers:

  • n(n + 1): 6 → 42, 8 → 72, 10 → 110. Also written as n² + n.
  • n³ − n = (n − 1) × n × (n + 1): 3 → 24, 4 → 60, 5 → 120, 6 → 210.

Worked example 3: a number times the next

8 : 72 :: 6 : ? 72 = 8 × 9, so the answer is 6 × 7 = 42.

Worked example 4: cube minus the number

6 : 210 :: 5 : ? 216 − 6 = 210, so the answer is 125 − 5 = 120. The same value is 4 × 5 × 6, three consecutive numbers.

When b is smaller than a, or the two look unrelated, check the digits.

Worked example 5: digit sum

12 : 3 :: 45 : ? 1 + 2 = 3, so the answer is 4 + 5 = 9.

Worked example 6: reversed digits

24 : 42 :: 37 : ? The digits are swapped, so the answer is 73.

Prime-based analogies usually pair a prime with the next one: 11 : 13 :: 17 : 19. If both numbers in the given pair are prime, check whether they are consecutive primes before trying arithmetic. Note that 13 − 11 = 2 and 19 − 17 = 2 here, but in 23 : 29 the gap is 6, so "add 2" would fail; the prime rule is the real one.

Sometimes more than one rule fits the given pair. 81 : 9 works as "square root" and also as "digit sum" (8 + 1 = 9). Apply each rule to c and compare with the options:

  • If only one result appears among the options, that is the answer.
  • If the question gives a second pair, the correct rule must fit it too.
  • If both still fit, prefer the more standard relation (squares and cubes over digit tricks).

Common traps: stopping at "square" when the answer is square + 1; confusing n(n + 1) with n²; forgetting that the rule must go in the same direction (a to b, then c to ?); and doing arithmetic on primes instead of recognising the prime sequence. For the word and letter types, see analogy types, and for numbers inside figures see missing number in figures.

Q1. 5 : 125 :: 8 : ? easy

✅ Answer: (b) 512

💡 Explanation: 125 is 5 cubed, so the answer is 8 cubed = 512. 64 would be 8 squared.

Q2. 4 : 17 :: 9 : ? easy

✅ Answer: (a) 82

💡 Explanation: 17 = 4² + 1, so the answer is 9² + 1 = 82. 81 is the trap answer for a plain square.

Q3. 7 : 56 :: 10 : ? medium

✅ Answer: (d) 110

💡 Explanation: 56 = 7 × 8, a number times the next number. So 10 × 11 = 110.

Q4. 3 : 24 :: 4 : ? medium

✅ Answer: (c) 60

💡 Explanation: 24 = 3³ − 3 = 2 × 3 × 4. So 4³ − 4 = 60, which is also 3 × 4 × 5.

Q5. 144 : 12 :: 169 : ? easy

✅ Answer: (b) 13

💡 Explanation: 12 is the square root of 144, so the answer is the square root of 169, which is 13.

What if two rules fit the first pair?

Apply both to the third number and see which result appears in the options. If both appear, prefer the rule that fits a second example when one is given; for example 81 : 9 fits both 'square root' and 'digit sum', so setters usually avoid it or add more pairs.

Which numbers should I learn by heart?

Squares up to 30, cubes up to 15 and primes up to 100. Most analogies hide one of these, and recognising 343 or 289 instantly saves the most time.

How is number classification different from number analogy?

Analogy asks you to repeat a relation between a pair. Classification (odd one out) asks which number breaks a pattern the others share. The same rules (squares, primes, digit sums) apply to both.

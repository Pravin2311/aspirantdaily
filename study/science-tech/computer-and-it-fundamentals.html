History and Generations

  • Charles Babbage designed the Analytical Engine and is called the father of the computer; Ada Lovelace wrote what is considered the first computer program.
  • Alan Turing laid the theoretical foundations of computing and artificial intelligence.

Memory Units

1 nibble = 4 bits; 1 byte = 8 bits; 1 KB = 1,024 bytes; then MB, GB, TB, PB, EB, ZB and YB, each 1,024 times the last.

CPU and Devices

  • The CPU ("brain" of the computer) has the ALU (arithmetic and logic), the control unit (directs operations) and registers.
  • Input devices: keyboard, mouse, scanner, microphone, joystick. Banks use MICR (Magnetic Ink Character Recognition) to read cheques; OMR reads marked answer sheets; OCR converts printed text into editable text.
  • Output devices: monitor, printer (impact: dot-matrix; non-impact: inkjet, laser), speaker, plotter. A touchscreen is both input and output.

Software and Languages

  • System software runs the computer — operating systems (Windows, Linux, macOS, Android), device drivers and utilities. Application software does user tasks — word processors, browsers, spreadsheets.
  • Linux, created by Linus Torvalds (1991), is open-source; Android is built on the Linux kernel.
  • Translators: a compiler converts the whole program at once; an interpreter converts and runs line by line; an assembler converts assembly language into machine code.
  • Number systems: binary (base 2), octal (8), decimal (10), hexadecimal (16, digits 0–9 and A–F).

Internet and Protocols

  • ARPANET (1969) was the forerunner of the internet. Tim Berners-Lee invented the World Wide Web at CERN in 1989.
  • IP addresses: IPv4 is 32-bit; IPv6 is 128-bit. DNS translates domain names into IP addresses; DHCP assigns IP addresses automatically.

Cyber Security

  • A virus attaches to a host file and needs a user action to spread; a worm spreads by itself across networks; a Trojan pretends to be useful software; ransomware encrypts data and demands payment; phishing tricks users into revealing details through fake messages or sites.
  • A firewall filters network traffic; two-factor authentication adds a second check beyond a password.
  • CERT-In (under MeitY) is India's national agency for responding to cyber security incidents. The IT Act, 2000 is the main cyber law; its Section 66A was struck down in Shreya Singhal v. Union of India (2015).

Q1. Which of the following memories is volatile?

✅ Answer: (b) RAM

💡 Explanation: RAM loses its contents when the power is switched off.

Q2. Banks use which technology to process cheques?

✅ Answer: (c) MICR

💡 Explanation: Magnetic Ink Character Recognition reads the special characters printed on cheques.

Q3. Which protocol is used to SEND email?

✅ Answer: (a) SMTP

💡 Explanation: SMTP sends mail; POP3 and IMAP are used to receive it.

Q4. An IPv6 address is how many bits long?

✅ Answer: (d) 128

💡 Explanation: IPv4 uses 32 bits and IPv6 uses 128 bits.

Q5. Malware that copies itself across a network without needing a host file is a:

✅ Answer: (b) Worm

💡 Explanation: Worms spread on their own; viruses need a host file and usually a user action.

🔁 Revise in 60 Seconds

  • Babbage — father of computer; generations: vacuum tube → transistor → IC → microprocessor → AI.
  • 1 byte = 8 bits, 1 KB = 1,024 bytes. RAM volatile; ROM non-volatile; EPROM — UV; registers fastest.
  • MICR cheques, OMR answer sheets. Compiler whole program; interpreter line by line.
  • HTTP 80, HTTPS 443, FTP 21, SMTP 25 (send), POP3 110 (receive). IPv4 32-bit, IPv6 128-bit. Worm self-spreads.

📌 Prelims Traps to Avoid

  • ✘ ROM is non-volatile, but it is still primary memory.
  • ✘ A switch sends data only to the intended device; a hub broadcasts to all.
  • ✘ Tim Berners-Lee invented the Web, not the internet.

What is the difference between RAM and ROM?

RAM (Random Access Memory) is volatile working memory that loses its data when the power is off and can be read and written freely. ROM (Read Only Memory) is non-volatile and stores permanent instructions such as the BIOS.

Which protocols are used for email?

SMTP (port 25) is used to send email. POP3 (port 110) and IMAP (port 143) are used to receive it — POP3 usually downloads messages to one device, while IMAP keeps them synchronised on the server.
